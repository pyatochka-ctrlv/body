# Де ховається Хвилюнчик?

Інтерактивна гра-візуалізація для уроку 1 «Чому голос ховається?» програми «Майстерня суперсил» (діти 7–8 років, онлайн у Zoom).

Діти пишуть у чат номер зони тіла, де відчувають хвилювання. Педагог одним тапом на пульті додає голос. На екрані зона підсвічується, з неї визирає Хвилюнчик, і поступово виходить теплова карта групи. Карта анонімна: на екрані дітей немає ні імен, ні кількості голосів.

---

## 1. Як відкрити екран і пульт

Посилання (після розгортання на GitHub Pages, див. розділ 4):

| Що | Адреса |
|---|---|
| **Екран** (його бачать діти) | `https://pyatochka-ctrlv.github.io/body/` |
| **Пульт** (бачите лише ви) | `https://pyatochka-ctrlv.github.io/body/?mode=remote` |

Найпростіше:

1. Відкрийте **пульт** у Chrome або Safari.
2. На пульті натисніть **«Відкрити вікно екрана»**. Відкриється окреме вікно екрана без зайвих панелей браузера.
3. Угорі пульта має з'явитися зелений індикатор **«Синхронізовано»**.

Важливо:

- Екран і пульт мають бути відкриті **в одному браузері на одному комп'ютері**. Chrome + Chrome підходить, а Chrome + Safari не синхронізуються.
- Карта зберігається в браузері. Якщо випадково перезавантажити сторінку чи закрити вікно, голоси нікуди не зникнуть.
- Звуки за замовчуванням вимкнені. Їх можна ввімкнути перемикачем **«Звуки»** на пульті.

### Пульт

- **Велика кнопка зони**: +1 голос.
- **−1** поруч: скасувати помилковий тап.
- **Сіре число**: скільки голосів у зоні. Його бачите лише ви.
- **«Підсумок»**: вмикає або вимикає фінальний екран. На ньому зони-лідери м'яко пульсують, Хвилюнчик усміхається і з'являється плашка з висновком.
- **«Скинути карту»**: очистити карту для нової групи (просить підтвердження).
- Клавіатура: `1`–`7` додає голос, `Shift` + `1`–`7` прибирає голос.
- Індикатор угорі:
  - зелений — «Синхронізовано»;
  - жовтий — «Оновлюю…»;
  - червоний — «Екран не відкрито». Натисніть на нього, щоб відкрити екран.

Якщо ви відкрили спершу екран, натисніть на ньому клавішу `R`, і відкриється пульт.

## 2. Як у Zoom показати саме вікно екрана (а не весь робочий стіл)

1. У Zoom натисніть **«Демонстрація екрана»** (Share Screen).
2. На вкладці **«Основне»** (Basic) виберіть **вікно браузера з екраном гри**, а не «Екран 1» / «Робочий стіл». Вікна підписані назвою сторінки:
   - **«Де ховається Хвилюнчик?»** — екран гри;
   - **«Пульт · Хвилюнчик»** — пульт. Його **не** вибирайте.
3. Якщо хочете, щоб діти чули звуки, поставте внизу галочку **«Поділитися звуком»** (Share sound).
4. Натисніть **«Поділитися»** (Share).

Так діти бачать лише гру. Пульт, чат і інші вікна залишаються видимими тільки вам.

> На macOS під час першої демонстрації Zoom може попросити дозвіл «Запис екрана» в Системних налаштуваннях → Конфіденційність і безпека. Надайте його й перезапустіть Zoom.

## 3. Як розставити вікна

```
┌──────────────────────────────────┬───────────┬──────────────┐
│                                  │           │              │
│   ЕКРАН ГРИ                      │  ПУЛЬТ    │  Zoom: чат   │
│   (саме це вікно демонструємо)   │  ~400 px  │  і учасники  │
│                                  │           │              │
└──────────────────────────────────┴───────────┴──────────────┘
```

- **Екран гри** — найбільше вікно. Він сам масштабується під будь-який розмір і завжди зберігає пропорції 16:9. Можна навіть розгорнути його на другий монітор.
- **Пульт** — вузьке вікно (близько 400 px завширшки) поруч із чатом Zoom. Так ви бачите повідомлення дітей і одразу тапаєте зону.
- Якщо монітор один, можна поставити пульт поверх кутка вікна екрана: діти бачать лише вікно, яке ви демонструєте, і пульт на демонстрацію не потрапить. Втім, надійніше, щоб вікна не перекривалися.
- Пульт і екран мають бути **окремими вікнами**, а не вкладками одного вікна. Zoom показує тільки активну вкладку.

### Сценарій на уроці

1. До уроку натисніть «Скинути карту» (якщо там лишилися голоси попередньої групи).
2. Увімкніть демонстрацію вікна екрана. Хвилюнчик тремтить біля силуету.
3. Попросіть дітей написати в чат номер зони (можна кілька).
4. На кожну відповідь з чату тапайте відповідну зону на пульті.
5. Коли всі відповіли, натисніть «Підсумок» і обговоріть: «У кожного Хвилюнчик ховається по-своєму, і це нормально».

## 4. Розгортання на GitHub Pages

1. Злийте гілку з грою в `main`.
2. У репозиторії відкрийте **Settings → Pages**.
3. У полі **Source** виберіть **Deploy from a branch**, гілку **`main`**, папку **`/ (root)`** і натисніть **Save**.
4. За 1–2 хвилини сайт буде доступний за адресою `https://pyatochka-ctrlv.github.io/body/`.

Збирати нічого не треба: це чисті HTML, CSS і JS.

Для перевірки без інтернету можна запустити локальний сервер у папці проєкту:

```bash
python3 -m http.server 8000
```

Після цього відкрийте `http://localhost:8000/?mode=remote`.

## Для розробника

```
index.html        — розмітка обох режимів + SVG силуету
css/common.css    — палітра, шрифт, конфеті-декор
css/screen.css    — екран (сцена 1920×1080, масштаб через transform) і стани Хвилюнчика
css/remote.css    — пульт
js/zones.js       — 7 зон і теплова шкала кольорів
js/store.js       — стан, localStorage, BroadcastChannel (+ fallback на подію storage)
js/art.js         — SVG Хвилюнчика та іконок зон
js/sound.js       — звуки через Web Audio (без файлів)
js/screen.js      — логіка екрана
js/remote.js      — логіка пульта
```

- Зовнішній запит один: шрифт Nunito з Google Fonts. Ілюстрації — inline SVG і CSS-анімації.
- Писати в стан може лише пульт. Кожна зміна збільшує `rev` і розсилається через BroadcastChannel. Якщо його немає, екран ловить подію `storage`. Екран раз на 1,5 с залишає «пульс» у localStorage і відповідає на `ping`, з цього пульт показує індикатор синхронізації.
- Звук грає у вікні пульта: там був клік, тож браузер не блокує аудіо. Zoom передає звук комп'ютера, якщо ввімкнено «Поділитися звуком».

### Структура стану (localStorage, ключ `khvylyunchyk:state:v1`)

```json
{
  "schema": "khvylyunchyk/v1",
  "rev": 12,
  "updatedAt": "2026-11-06T10:15:00.000Z",
  "session": {
    "id": "mh3k2x-ab12cd",
    "startedAt": "2026-11-06T10:00:00.000Z",
    "lesson": { "program": "Майстерня суперсил", "number": 1, "title": "Чому голос ховається?" },
    "group": null
  },
  "votes": { "head": 1, "cheeks": 0, "throat": 2, "heart": 3, "belly": 4, "hands": 0, "legs": 1 },
  "log": [ { "at": "2026-11-06T10:05:12.000Z", "zone": "belly", "delta": 1 } ],
  "summary": false,
  "settings": { "sound": false },
  "archive": [ { "session": { "...": "..." }, "votes": { "...": "..." }, "endedAt": "..." } ]
}
```

- `session` — одна «карта групи». Під час скидання карта з голосами потрапляє в `archive` (останні 20).
- `log` — журнал тапів із часом. З нього пізніше можна відновити хід заняття.
- `KHV.store.toSheetRow(state)` уже повертає «плаский» рядок для Google Таблиці (дата, урок, група, голоси за зонами, усього). Зараз нічого нікуди не відправляється. Щоб це додати, достатньо надіслати цей рядок, наприклад, у Google Apps Script.
